# API Contract

## REST Endpoints

### 1. Authentication
- `POST /api/v1/auth/login`
  - Desc: Authenticate and retrieve JWT token.
- `POST /api/v1/auth/refresh`
  - Desc: Refresh JWT token.

### 2. Transactions
- `GET /api/v1/transactions`
  - Desc: List transactions with pagination and filters (txid, amount, date).
- `GET /api/v1/transactions/{txid}`
  - Desc: Get detailed transaction metadata.

### 3. Entities
- `GET /api/v1/entities/{entity_id}/graph`
  - Desc: Retrieve 1-hop or 2-hop transaction graph for visualization.

### 4. Alerts
- `GET /api/v1/alerts`
  - Desc: Fetch anomalies generated by ML models.
- `PATCH /api/v1/alerts/{alert_id}`
  - Desc: Update alert status (Open, Investigating, Closed).

## Pagination Format
All list endpoints return paginated structures:
```json
{
  "data": [...],
  "meta": {
    "page": 1,
    "limit": 50,
    "total": 1200
  }
}
```
